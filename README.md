In this project, I created an interactive E-Commerce Sales & Profit Analysis Dashboard to analyze business performance across different states, categories, customers, payment modes, months, and product sub-categories.

The dashboard provides a clear view of important business KPIs and helps identify patterns and trends that can support better data-driven decisions.
